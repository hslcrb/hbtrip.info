# HBTrip.info 웹사이트

## 프로젝트 개요

이 프로젝트는 HBTrip.info 웹사이트의 소스 코드를 포함하고 있습니다. 웹사이트는 모던한 디자인과 사용자 경험을 제공하기 위해 다양한 디자인 요소와 기술을 활용하고 있습니다.

## 디자인 특징

### 리퀴드 글래스 디자인

최신 버전에서는 애플의 리퀴드 글래스 디자인을 적용하여 모던하고 세련된 UI를 구현했습니다. 리퀴드 글래스 디자인의 주요 특징은 다음과 같습니다:

- **반투명 효과**: 배경이 살짝 비치는 반투명 효과로 깊이감 제공
- **블러 처리**: backdrop-filter를 활용한 블러 효과로 유리 같은 질감 구현
- **미묘한 그라데이션**: 부드러운 그라데이션으로 자연스러운 빛 반사 효과 표현
- **얇은 테두리**: 0.8px의 얇은 테두리로 섬세한 디테일 강조
- **미묘한 그림자**: 여러 레이어의 그림자로 입체감 부여
- **부드러운 전환 효과**: hover 시 transform과 transition을 활용한 자연스러운 움직임

### 윈도우 에어로 스타일

기존의 윈도우 비스타 에어로 스타일에서 영감을 받아 현대적으로 재해석했습니다:

- **스크롤바 디자인**: 에어로 스타일의 스크롤바를 리퀴드 글래스 디자인으로 개선
- **모달 창**: 반투명 효과와 블러 처리로 에어로 스타일을 현대적으로 구현

### 다크 모드 지원

- 라이트 모드와 다크 모드 간 자연스러운 전환
- 각 모드에 최적화된 리퀴드 글래스 효과 적용
- 테마 토글 버튼을 통한 쉬운 모드 전환

## 파일 구조

- **sigak.html**: 메인 페이지 및 테마 토글 기능 구현
- **bdsc.html**: 업데이트 모달 및 스크롤바 스타일 정의

## 기술 스택

- HTML5
- CSS3 (backdrop-filter, 그라데이션, 트랜지션 효과 등)
- JavaScript

## 향후 개선 사항

- 모바일 반응형 디자인 최적화
- 추가적인 애니메이션 효과 구현
- 접근성 개선
