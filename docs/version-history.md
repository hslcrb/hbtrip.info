# 버전 히스토리

> 2025 한봄고등학교 수학여행 사이트의 전체 변천사.
> 각 커밋과 파일 변경 내역을 타임라인 순으로 정리.

---

## 개요

이 사이트는 2025년 8월 20일 첫 개발을 시작으로, 2025년 10월 15일 수학여행 당일까지 지속적으로 업데이트되었습니다.  
각 주요 업데이트 시점마다 기존 파일들의 이름에 접미사(버전 번호)를 붙여 보존하는 방식으로 히스토리를 관리했습니다.

총 **11개 타임라인 노드** (vFinal, v22, v22-2, v23, v24, v24-2, v26, v28, v31, vsarligs, 최신)에  
**33개 HTML 파일**이 분류되어 있습니다.
